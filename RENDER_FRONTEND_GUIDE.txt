DEPLOY FRONTEND TO RENDER - QUICK GUIDE

Step 1: Create Static Site
1. Go to Render Dashboard
2. Click "New +" → "Static Site"
3. Connect GitHub: saksham-koul-2003/curalink

Step 2: Configure Settings
Name: curalink-frontend
Branch: main
Root Directory: frontend
Build Command: npm install && npm run build
Publish Directory: build

Step 3: Add Environment Variables
REACT_APP_API_URL=https://curalink-backend-l45u.onrender.com/api
REACT_APP_ENV=production

Step 4: Deploy
Click "Create Static Site"
Render will build and deploy automatically

Your frontend will be available at:
https://curalink-frontend.onrender.com
